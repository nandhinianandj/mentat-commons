# Architecture Decision Records (ADRs)

This folder contains Architecture Decision Records (ADRs) for the Mentat Commons platform.

## What is an ADR?
An ADR is a short text document capturing a significant architectural decision, including its context, alternatives considered, chosen path, and consequences.
