# Mentat Commons Documentation Repository

This directory contains the canonical documentation for the Mentat Commons platform.

## 📁 Directory Structure

*   [PROJECT_PRINCIPLES.md](file:///home/bobbyd/playspace/mentat-commons/docs/PROJECT_PRINCIPLES.md): The platform constitution, outlining the core philosophies of evidence preservation and retrieval-first engineering.
*   [specs/](file:///home/bobbyd/playspace/mentat-commons/docs/specs/): Technical specifications for subsystems, modules, and data models.
*   [architecture/](file:///home/bobbyd/playspace/mentat-commons/docs/architecture/): Overall system maps, layer designs, and data flow documentation.
*   [adr/](file:///home/bobbyd/playspace/mentat-commons/docs/adr/): Architecture Decision Records documenting key design choices, options considered, and trade-offs.

## ✍️ Documentation Guidelines

1.  **Templates**: Always use the respective template (`TEMPLATE.md`) when creating new Specifications, Architecture docs, or ADRs.
2.  **Immutability of Principles**: All documents must align with the [Project Principles](file:///home/bobbyd/playspace/mentat-commons/docs/PROJECT_PRINCIPLES.md).
3.  **Traceability**: Cite file paths and issue/PR markers explicitly using markdown file link notation.
