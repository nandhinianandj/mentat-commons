# Technical Specifications

This folder contains detailed technical specifications for subsystems, modules, and schemas on the Mentat Commons platform.

## What is a Specification?
A specification is a formal description of a system component's requirements, data structures, public APIs, and flow-charts. It bridges high-level architecture maps with actual source code implementation.

## List of Specifications
*   [career-evidence-graph.md](file:///home/bobbyd/playspace/mentat-commons/docs/specs/career-evidence-graph.md): The core specification detailing the Career Evidence Graph, schemas, and verification pipelines.

## How to use
1.  Copy [TEMPLATE.md](file:///home/bobbyd/playspace/mentat-commons/docs/specs/TEMPLATE.md) to a new file named `subsystem-name.md` (e.g. `knowledge-ingestion-pipeline.md`).
2.  Fill in the sections.
3.  Ensure the specification matches the [Project Principles](file:///home/bobbyd/playspace/mentat-commons/docs/PROJECT_PRINCIPLES.md).
